## UX 핵심 원칙

1. **원스텝 시작**: 제품 설명만 입력하면 바로 시뮬레이션 가능 (타겟 조건은 기본값 있음)
2. **실시간 피드백**: 응답이 하나씩 도착할 때마다 화면에 표시 (기다리는 동안 지루하지 않게)
3. **점진적 공개**: 요약 → 상세 카드 → 세그먼트 → 리포트 순으로 depth
4. **명확한 면책**: "AI 시뮬레이션 결과이며 실제 조사를 대체하지 않습니다" 항상 표시
5. **다운로드 가능**: 리포트를 PDF/CSV로 내려받아 팀 공유·발표에 활용

## 색상 / 디자인 톤

- Primary: Deep Blue (#1a365d) - 신뢰감, 전문성
- Accent: Coral (#FF6B6B) - 인사이트 강조
- Background: Light Gray (#f7fafc)
- 카드: White + subtle shadow
- 톤: 깔끔하고 전문적, 과하지 않은 데이터 시각화
