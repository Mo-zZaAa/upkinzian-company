## 아키텍처 결정 사항

### 왜 이렇게 설계했는가

**핵심 원칙: "외부 의존 최소화, Upstage Solar API 하나로 끝내기"**

1. **DB 없음** — 데모/MVP라서 인메모리(dict)로 충분. Redis나 PostgreSQL 같은 외부 인프라 추가하면 배포 복잡해지고 비용 나감.
2. **큐 시스템 없음** — Celery/RabbitMQ 대신 Python asyncio로 동시성 처리. 50명 정도 시뮬레이션이면 충분히 감당 가능.
3. **Solar API가 전부** — 페르소나 응답 생성도 Solar, 인사이트 리포트 작성도 Solar. 하나의 API로 끝.
4. **비교 실험은 제외** — 일정 고려해서 Solar 단일 모델로 집중.

### 비용

- Upstage Solar: 시뮬레이션 1회(30명) ≈ $0.15, $70 크레딧이면 400회+ 가능
- 프론트엔드 배포(Vercel): 무료
- 백엔드 배포(Render): 무료 (15분 미사용 시 sleep)

### 기술 스택

```
Frontend: Next.js 14 (App Router) + Tailwind CSS
Backend:  FastAPI (Python 3.11)
AI:       Upstage Solar Pro 2 (OpenAI 호환 API)
Dataset:  nvidia/Nemotron-Personas-Korea (Parquet, 11만명 shard)
```

상세 아키텍처 문서: https://github.com/Mo-zZaAa/upkinzian-company/blob/main/docs/ARCHITECTURE.md

## 프론트엔드 (현재 상태)

### 화면 구성 (3단계 전환)

1. **입력 화면** — 제품 설명 + 타겟 조건(연령/성별/지역) + 질문 설정 + "시뮬레이션 시작" 버튼
2. **진행 화면** — 프로그레스 바 + 실시간 응답 도착 표시 + 라이브 통계
3. **결과 화면** — 3개 탭 (요약 / 응답 카드 / 리포트)
   - 요약: 긍정/부정 비율, 평균 구매의향, 매력포인트/우려 TOP5, 지불의향가
   - 응답 카드: 페르소나별 상세 응답 (나이/성별/지역/직업 + 점수 + 인용문)
   - 리포트: Executive Summary, 세그먼트 비교, 마케팅 카피 추천, 개선 제안

### 디자인

Claude Design으로 만든 UI 기반. Navy(#1a365d) + Coral(#FF6B6B) 컬러, 깔끔한 카드 스타일.

UX 설계 문서: https://github.com/Mo-zZaAa/upkinzian-company/blob/main/docs/UX_DESIGN.md

## 백엔드 (현재 상태)

### API 엔드포인트

```
POST /api/v1/simulate       → 시뮬레이션 시작 (simulation_id 반환)
GET  /api/v1/simulate/{id}  → 진행상황 + 결과 폴링
GET  /api/v1/simulate/{id}/report → 인사이트 리포트
POST /api/v1/personas/preview → 페르소나 미리보기 (5명)
GET  /api/v1/health          → 헬스체크
```

### 핵심 로직 (검증 완료)

- ✅ Solar API 연결 테스트 성공 — 자연스러운 한국어 구어체 응답 확인
- ✅ Nemotron 데이터셋 로딩 + 조건별 필터링 — 11만명 중 20대 여성 등 필터 동작 확인
- ✅ 3명 미니 시뮬레이션 돌려봄 — 페르소나별 경제상황/성격 반영된 응답 생성됨

### 테스트 결과 예시

> **25세 남자 서울 연구원**: "AI의 추천이 실제 나의 학습 패턴을 얼마나 정확히 반영할지 의문. 3,000~4,000원은 합리적."
> **28세 여자 서울 무직**: "지금 상황에서 월 3,900원은 좀 부담돼요. 1,000~2,000원 정도면..."

→ 페르소나 경제 상황에 따라 가격 반응이 현실적으로 달라짐!

## 배포 현황 및 이슈

### 프론트엔드 (Vercel) — ⚠️ 404 에러 발생 중

- `upkinzian-frontend` 레포를 Vercel에 연결해서 배포했으나 404 뜸
- 원인 추정: Framework Preset이 Next.js로 제대로 안 잡혔거나, 빌드 과정에서 문제
- **해결 시도 필요**: Vercel 대시보드에서 프로젝트 삭제 후 재생성 시 Framework를 반드시 "Next.js"로 선택

### 백엔드 (Render) — 🔄 배포 진행 중

- `upkinzian-backend` 레포를 Render Free tier로 배포 설정 완료
- Docker 기반 배포, 첫 구동 시 데이터셋(220MB) 자동 다운로드
- Free tier 특성상 15분 미사용 시 sleep → 발표 전에 미리 깨워둬야 함

### 로컬에서는 정상 동작

백엔드 로컬 실행 후 프론트 연결하면 전체 플로우 동작함:
```bash
# 백엔드
cd backend && source venv/bin/activate && uvicorn app.main:app --reload --port 8000

# 프론트
cd frontend && npm run dev
```
